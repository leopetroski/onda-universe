## Rendering components

- Real 3D: campus, procedural dessert and SC52 visualization.
- PBR library: painted metal, steel, glass, plastic, rubber, concrete, timber, sand, water, vegetation and ceramic.
- HTML UI: navigation, inspectors, metrics, workflows and parameter editors.
- Animation: ocean displacement, orbit, exploded assemblies and transitions.
- Deferred assets: HDRI environment, texture maps, compressed GLB/KTX2 assets and approved logo binary.
