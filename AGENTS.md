# Universe Engine development governance

Preserve the existing Crowd Surf game at root index.html. The engineering application belongs under engine/. Import the existing Alpha 0.3 HTML as the baseline before modifying it. Do not replace it with a new unrelated prototype.

Use one canonical application and incremental commits. Inspect existing code before changes. Keep demo data explicitly labeled. Maintain editable, connected, versioned objects and deterministic parameter calculations. Separate reusable blueprints from instances. Preserve official ONDA brand assets. Never infer usable fridge dimensions from external measurements. CAD exports are not fabrication-approved without validation.

Work on feature branches; run relevant tests and report actual results. No production merge or deployment without owner approval. Never expose secrets or modify other ONDA or MAKTO repositories without scope authorization.

Architecture: World, Object, Parameter, Dependency, CAD, Workspace, Data, Memory, Connection and Intelligence engines, implemented incrementally. First proof: cup dimensions -> tray geometry -> fridge capacity. Future updates extend the same application rather than creating separate HTML versions.
